# docs/

Guides for the people who use and build ProbeTab: setup for teachers and
builders, and troubleshooting.

- [phase0.md](phase0.md) is the runbook for Phase 0, the first sessions with a
  LabPro on the bench.
- [phase0-evidence.md](phase0-evidence.md) maps each fact in the facts file to
  the Phase 0 step whose trace can settle it, and lists those no step reaches.

The teachers' and builders' guides are not started (2026-11-16). Its licence is
the one the folder table in [README.md](../README.md) gives it.
