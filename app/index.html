ProbeTab

Classroom sensors in a browser tab. ProbeTab is a free, open-source app being built for the Vernier LabPro, the box that links classroom sensors to a computer. It is meant to run in a web browser on a computer or a Chromebook, with nothing to install.

Not ready for classrooms yet. ProbeTab is being built now, and has been tried with a real LabPro on the bench, not yet in a classroom.

What it will do

  • Connect to a LabPro over USB, straight from the browser.
  • Show readings as a live graph and a table.
  • Save a run as a spreadsheet file.
  • Work with a keyboard and with a screen reader.

For testers

These pages are technical on purpose. They check ProbeTab against a LabPro one command at a time, and they are not the classroom app.

  • The bench page is built to talk to a LabPro over USB, in Chrome or Edge.
  • The rehearsal is the same page with a pretend LabPro, so it runs with no hardware at all.
