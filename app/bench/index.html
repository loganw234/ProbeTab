ProbeTab bench page

Phase 0 from the browser: the bench script's steps over WebUSB, which needs Chrome or Edge. The project's site publishes it, and tools/bench/serve.py serves it to the computer it runs on alone.

Read CH1 resets the unit (Command 0). It does so only when the unit is idle or done, never when it is armed or busy. Data not yet retrieved is kept unless Discard is ticked, and then that data is lost.

A JSON file of every transfer, for tools/bench/from_browser.py. One connection per page; reload the page for another.
